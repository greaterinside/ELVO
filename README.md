# ELVO

Small, working demo apps. Each app lives in its own folder with its own README.

| App | What it does |
| --- | --- |
| [expense-tracker](expense-tracker/) | Receipts: photograph a receipt, AI logs the expense, an admin reviews team spend and pushes it to Tally. |

Keys, passwords and database details are never stored in this repository. Each
app's `.env.example` lists the settings it needs.
